# Cadence — From thought to finished words

## Style Prompt
A quiet, premium macOS product film. Warm paper canvas, generous editorial typography, large readable product close-ups, and a coral voice motif drawn from Cadence's actual icon. Native-looking but entirely fictional document windows. Precise, short motion follows the work: a pulse becomes words, Command changes intent, a clean draft becomes a document. No personal desktop, account data, history, API details, or browser chrome. The user authorized an illustrative runtime; label that honestly.

## Colors
- Canvas: #F5F3EE
- Ink: #252723
- Muted text: #62655E
- Cadence coral: #D95340 (from the coral app-icon family)
- Completion teal: #247D70
- Window paper: #FFFEFB

## Typography
- SF Pro / -apple-system for native UI and restrained, tightly tracked 88–132px titles.
- Georgia italic only for the human voice quotation; 44–52px.
- Body 30–38px, secondary UI 22–26px; no illegible desktop-wide footage.

## Motion
GSAP deterministic timelines. Fluid 0.45–0.7s scene dissolves with subtle scale; 0.2–0.4s UI responses; readable holds after each result. No endless animation. The waveform remains active during recording; lock stays visible when mode changes. Processing retains the rainbow indication through the draft reveal. Live words appear with the demo voice; long source completes before scrolling.

## What NOT to Do
- No personal recordings, screenshots, windows, names, prompts, or histories.
- No settings tour as the main story.
- No fabricated speed, privacy, model, or availability claims.
- No copied third-party workspaces, logos, music, or copyrighted stock footage.
- No neon backgrounds, busy transitions, meaningless charts, or tiny floating UI.

## Production disclosure
Illustrative product sequence using fictional sample content and scripted live transcription. Not a recording or benchmark of the shipping runtime. Brand icon is from this repository. All remaining graphics and sound design are produced for this film.
